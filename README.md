# Notebooks del curso: Inteligencia Artificial, nivel intermedio

Notebooks de Colab que usamos en las sesiones del curso (EstudIA 2026). Para abrir uno, usa el enlace que comparte
el profesor en clase. Ese enlace abre el notebook en Google Colab directamente desde este repositorio.

Después de abrirlo, usa **Archivo › Guardar una copia en Drive** para trabajar en tu propia versión.

Los notebooks descargan sus fotos y datos de un almacenamiento público del curso. Los créditos de las fotos están al
final de cada notebook.
